# Media Category Manager

WordPress plugin scaffold for managing attachment categories like media folders.

## Planned v1

- Media library category sidebar
- Hierarchical attachment category browser
- Category counts
- Filter media by attachment category
- Bulk add/remove categories
- Optional compatibility with MLA, Divi, Gutenberg and ACF

## GitHub updates

The plugin can check a configured GitHub repository for updates and lets the admin choose whether updates should come from the `main` or `develop` branch.
